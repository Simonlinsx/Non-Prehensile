# Matched FR3 + stock hand model

Source: official `frankarobotics/franka_description`, commit
`7aeeddc449edf8d62b594f9e36a81da53e7796f9`.
Expansion inputs are in `upstream_provenance.json`; model and mesh checksums
are in `robot_model_manifest.json`.

The vendored source retains upstream LICENSE and NOTICE. Only `robots/fr3`
and `robot_ee/franka_hand_white` mesh directories are distributed. Other robots'
downloaded meshes are ignored locally; this subset is intended for FR3 with the
stock hand only. No mesh referenced by the matched FR3 manifest is omitted.

`fr3_official.urdf` is the pinned expanded source. `fr3_isaac.urdf` and
`fr3_native.urdf` are generated by `scripts/prepare_fr3_robot_models.py`.
They retain the original workstation paths for traceability. Regenerate into
a new output directory when moving the checkout; do not overwrite inputs to
a running frozen batch. See [the baseline guide](../../../docs/FR3_SIMULATION_BASELINE.md).
